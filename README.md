# LargoVerse Landing Page

Interaktivní one-page prezentace LargoVerse s pulzujícím technologickým stromem, pěti informačními kartami a responzivním rozvržením bez scrollování.

## Živá stránka

[majkpowa.github.io/largoverse-landing-page](https://majkpowa.github.io/largoverse-landing-page/)

## Funkce

- stejná kompozice na počítači i mobilu;
- pulzující strom podle dodané vizuální předlohy;
- interaktivní karty O nás, Vstoupit, Možnosti, Začít a Pro investory;
- ovládání klávesnicí, focus management a zavření dialogu klávesou Escape;
- statický režim při zapnuté systémové volbě omezení pohybu;
- česká Open Graph metadata pro sdílení.

## Lokální spuštění

```bash
npm install
npm run dev
```

Produkční build:

```bash
npm run build
```

## Technologie

React, TypeScript a Vite.
